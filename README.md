# robosys2026
![test](https://github.com/Kaoru031/robosys2026/actions/workflows/test.yml/badge.svg)

標準入力から受け取った数値データを処理するLinuxコマンド集です。

## 含まれるコマンド
- `plus`: 標準入力から読み込んだ数値の合計を出力します。
- `stats`: 標準入力から読み込んだ数値の統計量（件数・合計・平均・最小値・最大値）を出力します。

```bash
git clone [https://github.com/Kaoru031/robosys2026.git](https://github.com/Kaoru031/robosys2026.git)
